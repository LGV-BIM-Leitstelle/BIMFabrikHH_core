# BIMFabrikHH

## Die BIMFabrikHH Hamburg

Die **BIMFabrikHH** ist eine Entwicklung der Stadt Hamburg im Rahmen des Projektes *Connected Urban Twins (CUT)*.

Geobasisdaten wie DGM, Stadtmodelle usw. sind eine wichtige Grundlage für die Grundlagenermittlung im Bauwesen.  
Diese Daten liegen oft als GIS-Daten vor. Um die BIM-Methode umzusetzen, ist eine Umwandlung dieser Daten ins IFC-Format
erforderlich.  
Daher wird angestrebt, Geobasisdaten aus heterogenen Formaten im IFC-Format mit relevanten Informationen
bereitzustellen.

### Vorteile sind:

- Wiederholende Prozesse werden durch diese Automatisierung vereinfacht und standardisiert.
- Ressourcen werden gespart.
- BIM-Nutzung in der FHH wird verbreitet.
- Usability im Masterportal wird verbessert.
- Eine Anwendung für alle.


## Development

### Installation

Python 3.11 is required.

The project uses poetry. Dependencies can be installed in the following way:

```
python -m pip install --user pipx
pipx install poetry
poetry install
```
